下载 `OtpClipboard-1.0.6.0-x64-Configured.zip`，完整解压后双击 `安装.cmd`。这是已编译的 Windows x64 离线安装包，包含自包含 .NET、Windows App Runtime、签名应用包和安装脚本，无需安装开发环境或重新编译。

本版本预设与当前使用配置一致：

- 自动复制验证码到剪贴板：开启。
- 只识别微软“手机连接”的通知：开启。
- 右下角即时提示卡：开启。
- 关闭窗口后驻留托盘：开启。

已有安装升级时保留设备原有设置；上述预设用于首次安装。安装需要管理员确认以信任自签名应用证书。证书公钥随安装包分发，私钥不分发。

新设备第一次使用：

1. 在微软“手机连接”中完成手机配对，并确认手机通知能进入 Windows 通知中心。iPhone 需开启蓝牙配对电脑的“共享系统通知”。
2. 打开“验证码剪贴板”，点击“授权通知访问”，允许系统授权。
3. 按需在应用设置中启用“开机自启动”。
4. 点击“预览测试通知”，使用虚构验证码 `246810` 检查提示卡；点击卡片后可在空白文本框粘贴验证。真实手机转发仍需用该设备实际验证。

Windows 通知访问授权、蓝牙/手机配对和系统启动授权属于每台设备，不能随 GitHub 文件迁移。安装包不包含本机短信、验证码、通知记录、日志、手机配对数据或任何账号凭据。

支持 Windows x64，应用包最低 Windows 10 1809；手机连接的实际支持条件由微软决定。自动复制会覆盖当前剪贴板，可在设置中关闭。校验文件为同一 Release 下的 `SHA256SUMS.txt`。
